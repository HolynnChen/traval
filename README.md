# Traval

一个加密的旅行手册页面。**内容需要大门密码才能解锁查看。**

## 在线地址

👉 **https://holynnchen.github.io/traval/**

打开后是一道智能门锁界面，输入密码并按 `#` 确认即可解锁。
验证通过后浏览器会记住密钥，**下次打开自动解锁**，无需重复输入。

## 实现说明

- **加密算法**：PBKDF2-SHA256（600,000 次迭代）派生密钥 → AES-256-GCM
- **解密位置**：完全在浏览器本地（WebCrypto），密钥不上传任何服务器
- **密钥缓存**：解锁成功后缓存派生密钥于 `localStorage`，用于自动解锁
  - 缓存的**不是密码明文**，而是 PBKDF2 派生出的密钥
  - 点击锁屏底部「清除本机记录」可移除
- **无密码时**：页面源码中只有锁屏界面与密文，不含任何行程明文

## 隐私

本仓库**只包含加密后的页面**。行程内容、地点、日期等全部在密文内，
没有密码无法还原。构建用的源码与数据保留在本地，不纳入版本控制。
